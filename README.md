# برنامه کارنامه دانش‌آموز

یک برنامه ساده برای ثبت نمرات و محاسبه معدل دانش‌آموز با زبان برنامه‌نویسی پایتون.

## امکانات
- دریافت نام دانش‌آموز
- دریافت تعداد درس‌ها
- ثبت نام درس‌ها و نمرات
- بررسی معتبر بودن نمرات (بین ۰ تا ۲۰)
- محاسبه میانگین نمرات
- بررسی وضعیت قبولی یا مردودی هر درس
- نمایش گزارش کامل نمرات دانش‌آموز
